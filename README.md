# EE140/240A Lab 2: gm/ID Design

Transistor lookup tables and MATLAB/Python examples for Lab 2.
Due to the github max file size, this repo only contains the nch_1v.mat and pch_1v.mat.
If you need to use nch_2v.mat and pch_2v.mat, please use this link for download : https://drive.google.com/drive/folders/1ftiU6YuKG1RCsZb160xxMLx3We3UT_Nj?usp=sharing

## Python

Install the required packages, then run an example from this folder:

```bash
python -m pip install numpy scipy matplotlib
python plot_across_l.py
```

Keep `look_up.py` and the `.mat` files in the same folder as your scripts. For scripts missing initialization, copy the imports and data-loading lines from `import_data.py`.

## MATLAB

Set this folder as the current folder. Run `import_data.m`, then run an example.
